ForceGeo

Every command that can move a valve should prove where it came from.

ForceGeo checks the claimed location of every operator, device and sensor against several independent signals. When the signals disagree, it holds the action before it reaches the pipeline, so one hijacked login cannot cut a country's supply route.

The problem

Location is trusted, and location is easy to fake

Austria's TAG and SOL pipelines carry gas between Italy, Austria and Slovenia, and on to Croatia. Operations on lines like these assume that a login, a GPS fix or a badge scan says where someone really is. Each of those can be forged on its own, and one forged command can reach every country the line connects.

Stolen remote access

A password is enough to reach the valves

Remote access into OT networks is often guarded by credentials alone. The 2021 Colonial Pipeline shutdown started from a single compromised VPN password. Nothing checked whether the session came from where the operator was supposed to be.

GNSS spoofing

Sensors take position and time from satellites

Leak detectors, inspection drones and SCADA timestamps depend on satellite signals. Cheap transmitters can shift a reported position or clock. Near a border, a shifted leak alarm can land with the wrong country's operator.

Faked field presence

Check-ins and inspection logs are self-reported

Contractors working across several countries confirm site visits from a phone app. A copied badge or a spoofed phone location makes an intruder look like normal maintenance.

How it works

Five stages between the request and the pipeline

1 · Intercept

Event arrives

A command, check-in or sensor report passes through a ForceGeo gateway in front of SCADA or the field app.

2 · Collect

Gather signals

GNSS position and time, cell and Wi-Fi fingerprint, network round-trip time, IP origin, movement history, hardware attestation.

3 · Check

Score each signal

Every signal is compared with the claimed location on its own. A score of 1 means fully consistent, 0 means it contradicts it.

4 · Fuse

Trust score

A weighted average, capped hard by any strong contradiction, plus an anomaly model trained on each asset's normal behaviour.

5 · Decide

Policy by impact

Reading data needs little trust; closing a valve on a cross-border line needs a lot. The result is allow, step-up or block, with a written reason.

trust     = Σ wᵢ·sᵢ / Σ wᵢ     over available signals
if any sᵢ < 0.25 (wᵢ ≥ 0.10)  → trust = min(trust, 0.35)
coverage  = Σ wᵢ of available signals
if coverage < 0.65          → decision at most STEP-UP

weights:  GNSS pos .15 · GNSS time .10 · Cell/Wi-Fi .15
          Network RTT .15 · IP origin .10
          Movement .15 · Device attest .20

Value

What operators and countries get

One login can't cut a country's supply route

A stolen password can no longer close the valve that feeds a neighbouring country. The attacker would also need to fake the network path, the radio environment, the device and a plausible travel history, all at once.

Sensor data you can trust across borders

Spoofed positions and clocks are caught at the source. Leak alarms reach the right national operator, and crews go to the right place.

Sits in front of what exists

ForceGeo runs as a gateway and an app SDK. No replacement of SCADA or field devices. Each decision is logged with its reason, which supports incident reporting under NIS2 in every EU country on the line.

Consistency and reliability

Built so it does not become the outage

Safety comes first

  • Emergency shutdown is never blocked. ForceGeo can only add friction to actions that make things less safe.
  • Step-up before block. In the grey zone the operator confirms with a second factor or a supervisor, so work continues.
  • Fail-open with alarm for the gateway itself, configurable per action class, so a ForceGeo fault cannot halt the pipeline.

Same input, same answer

  • Deterministic rules decide; the anomaly model only adjusts within bounds. Every decision can be replayed from its log.
  • Every verdict lists its reasons in plain language, as in the console above.
  • Degraded mode is explicit. When networks fail in one country, missing signals lower coverage instead of being treated as bad, and decisions fall back to local step-up.

Glossary

Every term on this page, in plain words

Scoring
Σ wᵢ·sᵢ / Σ wᵢ
A weighted average. Σ means "add up". For each signal i, multiply its weight wᵢ (how much we trust that kind of signal) by its score sᵢ (0 to 1), add the results, then divide by the sum of the weights used. See the worked example above.
Weight (wᵢ)
How much one signal counts. Device attestation counts most (0.20) because a stolen password on an unknown device fails it.
Score (sᵢ)
How well one signal agrees with the claimed location. 1 = fully agrees, 0 = clearly contradicts.
Cap / contradiction
If any important signal scores below 0.25, the trust score cannot go above 0.35, however good the rest look. One clear lie outweighs several agreeing signals.
Coverage
How much of the total weight is available. If cell, network and IP are down, coverage drops to 60% and ForceGeo asks for extra confirmation instead of deciding alone.
Step-up
Ask for more proof before allowing: a second factor, a supervisor code or a camera check.
Isolation Forest
A machine-learning method that finds unusual events by how easily they can be separated from normal ones. Used to learn each asset's normal behaviour.
Location signals
GNSS
Global Navigation Satellite System: the umbrella term for GPS (US), Galileo (EU), GLONASS (Russia) and BeiDou (China). Gives position and very precise time.
GNSS spoofing
Broadcasting fake satellite signals so a receiver computes a wrong position or time. Jamming is the cruder version: drowning the signal out.
RTT
Round-trip time: how long a challenge sent by our gateway takes to come back. Data in fibre covers at most about 200 km per millisecond, so a short RTT proves the device is near; a long one proves little on its own, because mobile networks add delay. ForceGeo compares each device with its own normal RTT.
IP origin / ASN
Every internet address belongs to a network with an Autonomous System Number. It shows whether a connection comes from the utility's own network, a mobile carrier, or a rented server abroad.
Cell / Wi-Fi fingerprint
The set of mobile towers and Wi-Fi networks a phone can see. Hard to fake remotely, because you would have to be physically there.
APN
Access Point Name: the gateway a SIM card uses to reach a network. Utilities and contractors often get a private APN, so their devices never touch the public internet. "Contractor APN" = traffic arriving through the contractor's own SIM network.
Device attestation
Proof from a chip inside the device (TPM or secure element) that it is a known, unmodified device. A stolen password on an unknown laptop fails this.
Pipeline and control
SCADA
Supervisory Control and Data Acquisition: the software operators use to watch and control a pipeline or grid remotely.
OT / ICS
Operational Technology / Industrial Control Systems: the computers that move physical things (valves, pumps, breakers), as opposed to office IT.
PLC
Programmable Logic Controller: a small rugged computer at the site that actually opens the valve.
Block valve (BV)
A large valve that can shut off a section of pipeline. Closing one stops flow to everything downstream.
Compressor station (CS)
A site that re-pressurises gas every 100–200 km so it keeps flowing.
Setpoint
The target value a controller holds, such as output pressure in bar.
ESD
Emergency shutdown: the safety action that stops the process. ForceGeo never blocks it.
TSO
Transmission System Operator: the company running the high-pressure gas or power network in one country.
PMU
Phasor Measurement Unit: a grid sensor that timestamps measurements with GNSS time. Wrong time can trigger wrong protection actions.
Security and comms
VPN
Virtual Private Network: an encrypted tunnel that lets someone reach an internal network from outside. If the password leaks, so does the tunnel.
VPS
Virtual Private Server: a cheap rented server, often used by attackers to hide where they really are.
SOC
Security Operations Centre: the team that watches alerts and responds to attacks.
Fail-open
If ForceGeo itself breaks, commands pass through with an alarm instead of everything stopping.
TETRA
A digital radio system used by emergency services and utilities. Works when mobile networks are down.
LoRa
Long-range, low-power radio used by remote sensors to send small readings over many kilometres.
NIS2
The EU directive that requires energy operators to manage cyber risk and report serious incidents quickly.
